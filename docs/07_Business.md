# Objetivo

Este documento define o modelo de negócio da plataforma FLCAD.

Seu propósito é garantir um crescimento sustentável, oferecendo produtos adequados para diferentes perfis de usuários.

---

# Filosofia

A FLCAD não vende software.

A FLCAD vende produtividade.

O cliente paga pelo tempo economizado, pela qualidade obtida e pela facilidade de uso.

# Missão Comercial

Criar uma plataforma acessível para iniciantes e suficientemente poderosa para profissionais e empresas.

---

# Princípio

Todo novo recurso deverá responder:

"Este recurso aumenta o valor percebido pelo cliente?"

Se a resposta for não, ele deverá ser reavaliado.

---

# Visão

A FLCAD buscará construir um relacionamento de longo prazo com seus usuários.

Nosso objetivo não é vender licenças.

Nosso objetivo é acompanhar toda a evolução do profissional, desde sua primeira captura até projetos industriais de alta complexidade.
