# Surface Pipeline

Pipeline conceitual: Region → Border Analysis → Shrink/Expand/Smooth → Patch/Multi-Solver → Repair/Optimization → Validation → Surface.

`SurfacePipeline` fornece steps de criação, reparo, refinamento e validação. FEL registra CREATE/FIT SURFACE, PATCH, BLEND, FILL, SWEEP, LOFT, OFFSET SURFACE, VALIDATE, OPTIMIZE e REBUILD.
