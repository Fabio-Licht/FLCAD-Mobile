# Autonomous Reconstruction 0.9.0

Autonomous Reconstruction converts an Engineering Cognition snapshot into an executable planning workflow. It behaves as a senior modeling planner: establishes dependencies, ranks strategies, exposes the next authorized action and recalculates revisions after user changes.

Executable means schedulable planning metadata. G-009 never creates B-Rep, CAD surfaces, solids, booleans, CAM data or STEP files.
