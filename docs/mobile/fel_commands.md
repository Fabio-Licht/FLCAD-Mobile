# FEL Native Commands

Functional Alpha commands: `SELECT REGION`, `EXPAND REGION`, `SHRINK REGION`, `SMOOTH REGION`, `SAVE PROJECT`.

CAD fitting, solid creation and export commands are registered as typed unsupported commands until their engineering adapters exist. This allows scripts to validate vocabulary while preventing false output or destructive mesh access.

Native functions include AREA, PERIMETER, CURVATURE, NORMAL, CENTER, DISTANCE, LENGTH, RADIUS and DIAMETER.
