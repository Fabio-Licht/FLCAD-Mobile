# Region DNA

`RegionDNA` combina histogramas de normais e curvatura, assinatura topológica, área, perímetro, conectividade e centroide. `RegionDNAMatcher` produz similaridade de 0 a 1 para reconhecer uma região após revisão de malha.

O DNA Alpha é determinístico e extensível. Adapters futuros podem adicionar descritores nativos/IA mantendo os campos versionados e a mesma API. O hash serve para cache; não é um hash criptográfico nem prova de identidade geométrica.
