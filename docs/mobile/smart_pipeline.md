# Smart Region Pipeline and Intent

`RegionPipeline` executa comandos independentes sobre uma seleção. `RegionScript` grava sequências reutilizáveis. Regras persistidas adicionam políticas como Border Shrink e remoção de ilhas.

`IntentEngine` interpreta analytics e padrões históricos para sugerir plano, eixo/diâmetro, curva guia ou operações recorrentes. Sugestões possuem confiança e ação explícita; nunca são executadas sem decisão do usuário.
