# Architecture Audit

The audit requires Project First, passive bootstrap, lazy loading, official runtimes, dependency graph, Workflow, Session, Analytics, Advisor, Property Inspectors, Workspaces, FEL, Undo/Redo and GeometryKernelAPI-only mutation. It rejects timers, automatic workers/isolates, duplicate domains, cycles, direct OpenCascade access, alternate STL parsing, simulated geometry and fallbacks.
