# Professional Surface Modeling Certification

The certificate covers Import → Recognition → Fitting → Topology → Continuity → Morph → Extend → Reduce → Fair → Boundary → Manufacturing → Advanced Surface. The native harness must emit 500 pipeline evidence records from `bearing.stl`; run `tool/professional_modeling_certification.dart` to validate and emit the official JSON.

Unsupported native operations are successful only when their exact diagnostic is present and the original handle remains unchanged.
